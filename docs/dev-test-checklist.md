## 0. 运行环境与启动方式

| 项 | 值 | 备注 |
|----|----|------|
| PowerPoint | Microsoft 365 16.0.20326（x64） | `C:\Program Files\Microsoft Office\root\Office16\POWERPNT.EXE` |
| Visual Studio | 2022 Community（含 Office/SharePoint 工作负载） | F5 调试即加载插件 |
| WebView2 Runtime | 152.0.4191.53 | 已装，Web 面板可跑 |
| 插件注册 | `HKCU\...\PowerPoint\Addins\PPTShapeLibrary` LoadBehavior=3, manifest=bin\Debug\*.vsto\|vstolocal | 本机已注册 |
| 数据目录 | `%APPDATA%\PPTShapeLibrary\`（items / packs / logs / webview2 / settings.json） | 已存在，含 `.builtin_installed` |

### 启动方式（三选一）
1. **推荐**：用 VS2022 打开 `PPTShapeLibrary.sln` → 设 `PPTShapeLibrary` 为启动项目 → **F5**。
   启动后 PowerPoint 会自动打开并加载插件（LoadBehavior=3）。
2. 已装好调试清单时，直接 `start powerpnt.exe` 也会加载（vstolocal 指向 bin\Debug）。
3. 每次改代码后需重新生成：`msbuild PPTShapeLibrary.sln /t:Rebuild /p:Configuration=Debug /restore`
   （VS 里 F5 会自动做）。

### 构建自检（改完代码先跑）
```powershell
msbuild PPTShapeLibrary.sln /t:Rebuild /p:Configuration=Debug /restore /nologo /v:m
# 预期：Build succeeded，bin\Debug\ 含 PPTShapeLibrary.dll/.vsto 与 WebUI\
```
日志：`%APPDATA%\PPTShapeLibrary\logs\app.log`（>1MB 轮转；Web 面板 JS 未捕获异常也会写 `[webview]` 前缀记录）。

### ⚠️ 数据现状提醒（影响可复测项）
- 本机 `items\` 已有历史收藏、`.builtin_installed` 已存在 → **"首次运行自动装 15 个内置素材"无法复测**；
  如需复测：退出 PowerPoint 后，把 `%APPDATA%\PPTShapeLibrary\items\*` 与 `.builtin_installed` 移到备份处再启动。
- 若要干净环境全面回归，可整体改名 `%APPDATA%\PPTShapeLibrary` 为 `..._bak`（会连设置一起重置，谨慎）。

## 9. 已知风险 / 待观察

> ✅ = 已修复（2026-07 第四批）；其余仍在观察。

1. ✅ **文本查找替换**：改用「全文重读 + 已替换游标推进 + 单形状 2000 次兜底」，防重入/防漂移；跳过异常形状并计数提示；操作加 WaitCursor。
2. ✅ **文字清理的格式代价**：整段重设前记录首字符格式、重设后回刷字体（名称/字号/颜色/加粗）；不再无声丢格式（跨段混排仍统一为首段格式，弹窗已说明）。
3. **整稿收藏/应用**遍历每页每形状，页数多时偏慢（异常已逐形状 try/catch；整稿收藏经 Ribbon 触发时为主线程，超长文档注意观察卡顿）。
4. ✅ **图片网格**：改为 contain 等比完整显示并居中，不裁切、不溢出单元格、不重叠。
5. **ActionSettings 移除**在个别自绘/组合形状上可能抛异常——已被 catch，测试时留意计数是否偏小。
6. ✅ **素材包导入**：冲突即新 id；现返回 conflicts 计数，前端 toast 明示"× 个冲突已自动改名导入"。
