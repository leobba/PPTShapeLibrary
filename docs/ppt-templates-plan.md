# PPT 整套模板：展示与插入功能计划（待实现）

> 背景约束：无服务器存放 PPT 资源；插件离线优先（C3）；未来开源（素材包格式 .ppack.zip v1.1 已就绪）。

## 需求
在插件内提供"PPT 整套模板"的浏览与插入：像模板网站一样按分类浏览多套完整 PPT，
点击可预览并插入（追加到当前文稿 / 或新建文稿）。

## 无服务器资源承载方案（按本项目贴合度排序）

### A. 本地模板目录索引（最贴合离线约束）
- 插件设置配置"模板文件夹"（本地或 OneDrive/网盘同步目录）；
- 启动/刷新时扫描目录内 `.pptx`：生成封面与每页缩略图 → 库内展示卡片；
- 插入 = 把该 pptx 全部页面合并进当前文稿，或作为新文稿打开。
- 优点：零体积/零服务器/用户自扩充/网盘多设备同步；缺点：换机需带文件。

### B. 插件内置打包（精品少量预置）
- 挑 3~8 套设计好的模板随安装分发（首次运行导入，模式同 InstallLibraryContent）。
- 适合开箱即用的招牌模板；体积随模板增长。

### C. 素材包生态扩展（为开源铺路，格式即现成的 .ppack.zip v1.1）
- manifest 泛化出"整套模板包"：携带 `deck.pptx` + 每页 `preview.png`；
- 分发靠点对点 zip（微信/网盘），与现收藏素材包同一条导入路径。

### D. 开源后：模板仓库当服务器（远期）
- GitHub 仓库存 pptx；"模板市场"页读仓库索引 json + 封面图（GitHub 当图床）；
- 下载 zip → 本地库。符合开源定位。

### E. 商业轻托管（仅当要给别人"在线挑"才需要，远期）
- 封面图放免费静态托管，文件本体走 A/C。
