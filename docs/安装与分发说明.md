# PPTShapeLibrary 安装与分发说明

> 发布产物：`publish/`（ClickOnce 本体）与 `dist/`（完整分发包），均由
> `scripts/package-release.ps1` 一键生成，已加入 .gitignore。
> 版本：1.0.1.0（`PPTShapeLibrary/PPTShapeLibrary.csproj` 的 `ApplicationVersion`）

## 方式一（推荐）：带环境检测的安装器 `dist/`

```
dist\
  安装 PPTShapeLibrary.exe     ← 双击这个（环境检测 + 安装引导）
  App\                        ← 插件本体：PPTShapeLibrary.vsto + Application Files\（请勿单独移动/删改）
  离线安装包\说明.txt           ← 可选：放入官方离线包即可离线安装
  安装说明.txt
```

> 为什么是 `App\` 而不是 `setup.exe`：`setup.exe`（ClickOnce 引导程序）内烤入了**发布机上的绝对 URL**，
> 拷到别人机器/别的目录后不可用；而 `.vsto` 部署清单内是**相对路径**（`Application Files\…`），
> 安装源就是它所在目录 —— 所以安装器改为调用 `VSTOInstaller.exe /Install "<dist\App\PPTShapeLibrary.vsto>"`，
> 分发到任何位置都能装。

**安装器做了什么**（源码 `installer/`，.NET 4.7.2 WinForms）：
1. 打开即**自动检测**四项环境，逐项显示 ✓/✗ 与版本号：
   | 检测项 | 检测方式 | 必需性 |
   |---|---|---|
   | Microsoft PowerPoint | 注册表 `App Paths\POWERPNT.EXE` | 必需 |
   | .NET Framework 4.8 | `NDP\v4\Full` 的 Release ≥ 528040 | 必需 |
   | VSTO Runtime 4.0 | `VSTO Runtime Setup\v4R`（x86/x64 视图） | 必需 |
   | WebView2 Runtime | `EdgeUpdate\Clients\{F3017226-…}`（机器/用户级） | 建议（缺失只降级界面） |
2. **同时检测"是否已安装过"**（读控制面板卸载项）：已装则显示提示并提供「**卸载旧版本**」按钮
   （执行 `VSTOInstaller.exe /Uninstall <已装清单>`，并清理构建期残留的 `|vstolocal` 注册）——
   用于解决"换位置安装时报已安装另一版本"的问题；
3. 缺失项右侧按钮：
   - **下载安装**：打开官方下载页（联网引导）；
   - **安装本地包**：若 `离线安装包\` 内有 `ndp48*.exe` / `vstor*.exe` / `MicrosoftEdgeWebview2Setup.exe`，改为静默安装（请求 UAC）；
4. 装完点「**重新检测**」；
5. 必需项全 ✓ 后「**开始安装**」可用 → 调 `VSTOInstaller /Install` 装 `App\PPTShapeLibrary.vsto`
   （若失败自动回退为"打开 .vsto 走安装向导"），并以"是否真的出现安装记录"判定成功；
6. 底部日志记录每一步。

> **分发**：整个 `dist` 目录打包发给对方，双击其中的 `安装 PPTShapeLibrary.exe` 即可；
> 对方缺什么，安装器会明确列出并给出安装入口。
>
> 安装器自身需 .NET Framework **4.7.2+**（Win10 1809+/Win11 已内置）；未签名 exe 首次运行可能被
> SmartScreen 拦一下 → 「更多信息」→「仍要运行」。

### 一键重新打包
```powershell
cd E:\code\PPTShapeLibrary
.\scripts\package-release.ps1                    # 默认 1.0.1.0
.\scripts\package-release.ps1 -Version 1.0.2.0
```

### 离线安装包（推荐给他人 / 内网环境）
微软下载中心的直链（`fwlink`、`download/details.aspx`）**会不定期调整或下线**——实测
`go.microsoft.com/fwlink/p/?LinkId=2124703`（WebView2）与 `details.aspx?id=48217`（VSTO）已失效。
因此安装器的下载按钮指向**稳定的官方文档页**（不会 404）：

| 组件 | 官方页面（安装器打开的地址） | 离线包文件名（放入 `离线安装包\`） |
|---|---|---|
| .NET Framework 4.8 | https://dotnet.microsoft.com/download/dotnet-framework/net48 | `ndp48-x86-x64-allos-enu.exe` |
| VSTO Runtime 4.0 | https://learn.microsoft.com/visualstudio/vsto/how-to-install-the-visual-studio-tools-for-office-runtime-redistributable | `vstor_redist.exe` |
| WebView2 Runtime | https://developer.microsoft.com/microsoft-edge/webview2/#download | `MicrosoftEdgeWebview2Setup.exe` |

**最稳的分发做法**：事先把这三个官方安装包下载好，放进 `dist\离线安装包\`，再整个目录打包发给对方。
对方双击安装器后，缺失项会直接显示「**安装本地包**」，静默安装、**完全不依赖网络与链接有效性**。

## 方式二：直接用 ClickOnce（无环境检测）
环境已确认齐备时，可只用 `publish/`：双击其中的 `setup.exe` 安装（细节见下文）。

## 三、前置条件（目标机器）
| 依赖 | 说明 | 检查方式 |
|---|---|---|
| PowerPoint | 2016 / 2019 / 2021 / M365（桌面版，x86 或 x64 均可） | — |
| .NET Framework 4.8 | 插件运行库（Win10 1809+ / Win11 通常已内置） | 注册表 `HKLM\SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full` 的 Release ≥ 528040 |
| Visual Studio 2010 Tools for Office Runtime（VSTO Runtime 4.0） | VSTO 加载项运行时 | 控制面板已安装程序里找 "Microsoft Visual Studio 2010 Tools for Office Runtime" |
| WebView2 Runtime | 界面渲染（Win10/11 通常随 Edge 已内置） | 已安装程序里找 "Microsoft Edge WebView2 Runtime" |

> `setup.exe` 会自动检测并引导安装 **VSTO Runtime**（已配置引导包）；.NET 4.8 与 WebView2 需目标机已有（正常系统均已具备）。

## 四、安装（双击 setup.exe）
1. 取得整个 **`publish` 目录**（三个内容：`setup.exe`、`PPTShapeLibrary.vsto`、`Application Files\`）；
2. **关闭 PowerPoint**；
3. 双击 `setup.exe`：
   - 若出现"未知发布者/是否安装"提示 → 点 **安装**（当前使用临时证书签名，属正常；正式对外发布可换成正式代码签名证书）；
   - 若提示安装 VSTO Runtime → 按提示完成（或先手动安装）；
4. 安装完成后打开 PowerPoint → **「素材库」选项卡**应出现。

> 安装本质：ClickOnce 会把文件放到 `%LOCALAPPDATA%\Apps\2.0\...` 缓存，并在
> `HKCU\Software\Microsoft\Office\PowerPoint\Addins\PPTShapeLibrary` 注册加载项（LoadBehavior=3）。

## 五、卸载
- **控制面板 → 程序和功能** → 找到 `PPTShapeLibrary` → 卸载；
- 如需彻底清理（含数据）：卸载后再删除 `%APPDATA%\PPTShapeLibrary`（素材库数据/设置/备份/日志）。

## 六、分发给他人
- 把 **整个 `publish` 目录**打包（zip）发给对方，对方解压后双击其中的 `setup.exe` 即可；
- 部署清单内**不含绝对路径**（已验证），因此放到任意目录/盘符都能安装；
- 对方无需开发环境，也无需本仓库源码。

## 七、更新版本
1. 修改 `PPTShapeLibrary/PPTShapeLibrary.csproj` 的 `<ApplicationVersion>`（如 1.0.1.0 → 1.0.2.0）；
2. 重新发布：
   ```powershell
   & "C:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" `
     "E:\code\PPTShapeLibrary\PPTShapeLibrary\PPTShapeLibrary.csproj" /t:Publish /p:Configuration=Release `
     /p:ApplicationVersion=1.0.2.0 /p:IsWebBootstrapper=true `
     "/p:GenerateBootstrapperSdkPath=C:\Program Files (x86)\Microsoft SDKs\ClickOnce Bootstrapper\" /nologo /v:m
   ```
3. 产物在 `PPTShapeLibrary\bin\Release\app.publish\`，复制到 `publish\`（保持 `InstallUrl` 一致）；
4. 用户端下次启动插件时会提示更新（或重新运行 setup.exe 覆盖安装）。

> 注意：`PublishUrl/InstallUrl` 在本地测试时用 `file:///…/publish/`；若要"从网络更新"，需把 publish 内容放到 HTTP/UNC 位置并重新发布。当前本地部署不含绝对 URL，不受影响。

## 八、开发版 vs 正式版
| | 开发版（F5 / vstolocal） | 正式版（本说明） |
|---|---|---|
| 注册方式 | `HKCU\…\Addins\PPTShapeLibrary` 指向 `bin\Debug\PPTShapeLibrary.vsto\|vstolocal` | ClickOnce 安装到 `%LOCALAPPDATA%\Apps\2.0` 并注册 |
| 文件来源 | 直接读仓库 `bin\Debug`（改代码即时生效） | 读 ClickOnce 缓存（安装包快照） |
| 卸载 | 删除该注册表项（关闭 PowerPoint 后） | 控制面板卸载 |
| 并存 | 两者**不能并存**：正式版安装后会覆盖同一个注册表键；开发调试前建议先卸载正式版 |

## 九、常见问题
| 现象 | 处理 |
|---|---|
| PowerPoint 里没有「素材库」选项卡 | ① 确认已装 VSTO Runtime；② 文件 → 选项 → 加载项 → 管理"COM 加载项"里勾选 PPTShapeLibrary；③ 重启 PowerPoint |
| 面板空白 / 提示缺少 WebView2 | 安装 Microsoft Edge WebView2 Runtime |
| 安装时提示"未知发布者" | 临时证书签名所致，点继续即可；对外发布建议购买/生成正式代码签名证书 |
| **安装报 `AddInAlreadyInstalledException`（"已安装另一版本的自定义项，不能从该位置升级"）** | 原因：本机已装过一份、且这次从**不同位置**安装（ClickOnce 不允许换位置升级）。解决：安装器上点「**卸载旧版本**」按钮（会自动执行卸载并清理开发式注册残留），或到 控制面板 → 程序和功能 → 卸载 `PPTShapeLibrary`，然后重新点「开始安装」 |
| **不要双击 `bin\Release\PPTShapeLibrary.vsto`** | 那是**构建产物**：直接运行会把它注册成开发式加载项（`…|vstolocal`），与安装器装的正式版抢注册表，并导致后续安装报"已安装另一版本"。安装**只用** `dist\安装 PPTShapeLibrary.exe`（或 `dist\ClickOnce\setup.exe`）。已经误注册时：安装器「卸载旧版本」会自动清理，或手动删除 `HKCU\Software\Microsoft\Office\PowerPoint\Addins\PPTShapeLibrary` |
| 素材库数据在哪 | `%APPDATA%\PPTShapeLibrary\`（items 素材、backups 自动备份、logs 日志、settings.json、toolprefs.json） |
| 卸载后想保留数据 | 不要删除 `%APPDATA%\PPTShapeLibrary` |
